Privacidade

Política de privacidade simplificada.

Este site é essencialmente um portfólio estático. O objetivo desta página é explicar, de forma clara, o que é exibido aqui e como eventual contato acontece.

Dados coletados

Na versão atual do site, não há formulários próprios, área de login nem banco de dados público para cadastro de usuários.

Contato

Quando você usa o link de email, a conversa passa a acontecer no seu cliente de email e nas ferramentas normalmente associadas a esse envio.

Atualizações

Se o site passar a usar analytics, newsletter, formulário ou integrações adicionais, esta página deve ser atualizada para refletir a nova operação.

Resumo prático

  • O site foi estruturado como coleção de páginas estáticas servidas no Cloudflare Workers.
  • Os links internos e o feed do blog servem para navegação e descoberta, não para rastrear usuários.
  • Para dúvidas sobre privacidade, o contato principal é pedrocampelo.fgv@gmail.com.
